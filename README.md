# Content

**misc** is the place where I add most of the code I want to preserve as and use as reference for any project. Here you may find algorithms, data structures and genral-purpose scripts of variuos types. Some stuff I add might come from old code I wrote in either my Master or Bachelor, or it can be new code I write in spare time. The purpose is to populate this folder with any content I could find useful for educational purposes. Below a quick documentation of what you can find.

Documentation is poor and I try every now and then to improve it!

## Shell

Collection of scripts written either in Bash or CShell. Maily automation scripts for EDA tools, EDA environment or C programming.

## Markwown

Advanced usage of Markdown for software documentation. In this examples, you can find some useful examples of Markdown, PlantUML integration and other useful examples that can be used for documenting any kind of software design project.

## Tcl

Tcl is widely used for electronic design as is the main interface with EDA Tools. Here i plan to add Tcl scripts / procedures specifically made for ASIC design purposes.

## C

Here I add code related Algorithms, Data Structures, Operating systems and Embedded C.

## Asm

Collection of programs written in ARM or x86 assembly for didactical purposes. Most of this code comes from Computer Architecture classes.
